# Vicky Mans Wear Website

Includes:
- Main shop website
- Product cards with size, price and direct WhatsApp enquiry
- Admin panel at `admin.html`
- Admin login: username `deva`, password `123123`
- Add/edit/delete products, set price, category, badge, details and sizes
- Shop settings and JSON backup
- Responsive mobile design

## Important
This admin panel is a **static/demo admin panel**. Product data is stored in the browser's localStorage, so it is not a secure multi-user server backend. For a real online shop where changes are visible to all customers from every device, a database/backend (or a service such as Firebase/Supabase) is needed.

## GitHub Pages
Upload all files/folders to `<your-username>.github.io` and enable Settings -> Pages -> Deploy from branch -> main -> root.
